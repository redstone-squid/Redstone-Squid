# Squid Reactivity

`squid-reactivity` tracks changes to Python models and groups updates into
transactions. Squid UI uses it to update components when the values they read
change.

For UI code, start with [sharing state between components](../squid-ui-architecture.md#reusable-reactive-models).
For standalone use, see the [package README](https://github.com/redstone-squid/Redstone-Squid/blob/master/packages/squid-reactivity/README.md).
