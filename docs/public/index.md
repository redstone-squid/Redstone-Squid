# Redstone Squid

Redstone Squid is a Discord bot for finding Minecraft redstone builds, submitting new
builds for review, and tracking records.

- [Use Redstone Squid](use-the-bot.md) to find a build or submit one of your own.
- [Run your own instance](docker.md) with Docker Compose.

[Squid UI](squid-ui.md) is the Python framework behind the bot's interactive screens.
Start there if you're building an interface for your own application.
