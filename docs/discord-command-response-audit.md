# Discord command response audit

The catalogue can share moderator-only build information in a channel. Archive moves can
leave two copies visible, the owner sync shortcut can clear global commands from a DM, and
the Redstoner panel can leave a member's role removed. Two consent prompts also direct
readers to an unregistered command.

## Scope

The inventory comes from the loaded Discord command tree and the configured production
extensions. It covers 25 production slash commands, four message actions, six prefix commands,
mention search, and the first-party development commands. Each entry includes its initial
response and the controls, confirmations, and follow-ups it opens. Jishaku is a development
dependency with its own commands. Unprompted notifications and listener-only automation are
outside the command inventory.

Findings use P1 for unintended disclosure or a partial write with visible side effects, P2 for a
blocked or misleading workflow, and P3 for discoverability, consistency, or presentation issues.

## Verification

Source review followed each registered entry through its response, relevant callbacks, and
shared delivery and error policies. Reproductions use Simcord or local test doubles. The Discord UI gallery captures Components V2 payloads and approximates their layout in
HTML. Native desktop and mobile styling, keyboard navigation, and screen-reader reading order
remain client acceptance checks. Use a test server and compare what staff and non-staff members can see.

The most useful client checks are the full catalogue with filters and a card open, the
submission form with validation and file actions, account tabs with empty and populated
Notifications, and a long poll review. Use a narrow viewport, the locale with the longest
available labels, and both themes. Check that control labels remain distinguishable, tab and modal
focus follows the task, failures are readable without color, and the primary action stays within
easy reach. [Bot screen conventions](bot-screens.md) · [Discord component budgets](https://docs.discord.com/developers/components/reference)
