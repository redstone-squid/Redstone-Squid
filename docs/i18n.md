# Translating user-facing text

Python messages use Fluent through the independent `squid-i18n` package. A message
captures its Python values when it is created and resolves when a reader's
`Localization` is available. Domain code can carry messages without importing a UI
or transport package.

## Write a declaration

Give each message a stable ID describing its owner and purpose. Keep that ID when
editing the English wording. `tr` accepts one literal Python t-string containing a
Fluent message, optionally with attributes:

```python
from squid_i18n import NUMBER, tr

message = tr(t"build-saved = Saved {title}.")
summary = tr(t"""
    build-count = {{ {NUMBER(count)} ->
        [one] {NUMBER(count)} build
       *[other] {NUMBER(count)} builds
    }}
    """)

search = tr(t"""
    build-search =
        .label = Search builds
        .placeholder = Enter a title or creator
    """)
placeholder = search.attribute("placeholder")
```

Fluent braces are doubled in Python. Python interpolations keep single braces.
The extractor parses the literal structure without importing or executing the
application; captured values never become Fluent syntax. Multiline patterns retain
line breaks. Fluent trims indentation and trailing pattern whitespace; use a Fluent
string literal such as `{{ "\\u000A" }}` only when an exact trailing newline matters.

Interpolation values must have names: `{title}`, `{NUMBER(count)}`, or
`{(title := build.title)}`. The last form gives a computed value its catalog argument
name. Repeated names must capture the same value. Python conversions such as `!r`
and format specifications such as `:.1f` are rejected. Compute diagnostic text in a
named variable, or use typed formatting expressions:

```python
from squid_i18n import DATETIME, NUMBER, tr

price = tr(t"build-price = {NUMBER(amount, style='currency', currency='USD')}")
time = tr(t"build-created = {DATETIME(created_at, date_style='long')}")
```

Capture identifiers as text, for example `{(build_id_text := str(build_id))}`, so
locale-aware numeric grouping cannot alter a Discord mention or command argument.
Use `NUMBER` for quantities.

Formatting options must be Python literals. Number precision, grouping, and date
styles appear in Fluent for translators to adjust. Currency, numeric style, and
time zone remain developer-owned binding options. `DATETIME` requires an aware
datetime when given a time. Ordinary datetime and UI timestamp interpolations keep
Discord's timestamp tokens; `DATETIME` explicitly requests locale-formatted text.

An attribute lookup validates its name immediately. An attribute-only message can
be carried around, but resolving it without choosing an attribute is an error.

## Resolve at the presentation boundary

Pass messages directly to components, interpolate them inside another message, or
combine them with `Message.join` and `+`. `str(message)` is deliberately an error.
`Localization` contains immutable resource snapshots, with an English fallback.
The application builds these snapshots in `squid.core.i18n.localization_for` and
installs one with `localization_scope` for the reader.

Ordinary interpolated strings are escaped when emitted as Discord Markdown, and
mentions are neutralized. Select expressions compare the original values. Use
`plain` for literal text or `raw_md` for deliberately trusted Markdown. `source_text`
renders English independently of the active reader and supports plain diagnostic
output. Message composition retains deferred children and their markup policy.

Discord command metadata uses `to_locale_str(message)`, which accepts a
parameter-free declaration and stores it on `locale_str`. Metadata generated by
discord.py from signatures and docstrings has declarations in
`squid/bot/command_texts.py`. Registration checks these against the generated English
metadata before attaching them. Update those declarations when changing signatures.

## Maintain catalogs

The application owns `locales/en/messages.ftl` and its `messages.json` binding
manifest. Framework distributions own the same files beneath their package's
`locales/en/` directory, so their wheels carry their resources. Translations live in
the corresponding BCP-47 locale directory, for example `locales/zh-CN/`.

- `just i18n-extract` regenerates English FTL, argument metadata, and source locations.
- `just i18n-update` refreshes extraction and reports translations needing review.
- `just i18n-init zh-CN` creates empty translation resources without overwriting work.
- `just i18n-check` checks generated files and validates supplied translations.
- `just i18n-review zh-CN` records reviewed source fingerprints after translator review.

Catalog freshness is checked on push and in CI, so intermediate commits can leave
generated files stale. Run `just i18n-extract` before pushing changes that affect
messages or their source locations.

Translate `messages.ftl`; optional additional `.ftl` files can hold shared terms.
Missing entries or attributes fall back to English. Invalid syntax, duplicate IDs,
cycles, missing references, unknown functions, unbound variables (including through
message references), and attempts to override developer-owned options fail checks.
Runtime resolution also falls back on translation failures and logs the ID and
locale without captured values. A broken English source raises a resolution error.

Fingerprints detect source changes for review; they are not message IDs. Updating
a catalog preserves translation text and comments. `source-revisions.json` records
the reviewed English revision. Entries removed from source are reported as obsolete.

The migration retained all 168 nonempty Chinese translations: 150 match current
source declarations, and 18 from removed showcase screens are kept in
`locales/archive/zh-CN-showcase.json` for reuse. Reused English wording can map to
several owned Fluent declarations.

Supported application locales are declared in `SUPPORTED_LOCALES`. Add the locale
there after preparing its resources. The web frontend's localization is separate.

The compiler dependency is pinned to the
[Redstone Squid fork](https://github.com/redstone-squid/fluent-compiler), which fixes
precision-sensitive plural selection and decimal numeric variants. The adapter uses
its escaping integration so values remain raw until formatting emits them.
